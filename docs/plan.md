## Decisions

- 2026-10-21: Use one FLAIR channel, all nonzero tumour labels, axial 2D slices, and 128×128 working resolution. Keep full source metadata for reconstruction.
- 2026-10-21: Normalize each FLAIR volume using positive finite voxels' 1st and 99th percentiles; set background to zero. The same rule applies to every split.
- 2026-10-21: Shuffle patients and slices within each patient during training so each compressed volume is loaded once per epoch without a slice cache.
- 2026-10-21: Choose SAM's highest predicted IoU mask for each U-Net-derived component box. Empty predictions produce empty SAM outputs. Tune padding on fixed validation patients only.
- 2026-10-21: Select thresholds and 2D component cleanup by mean whole-volume validation Dice across all 73 validation patients. Select box padding by mean whole-volume validation Dice on twelve seeded validation patients. Reuse each SAM image embedding across the padding variants.
- 2026-10-22: Report the negative held-out SAM Dice result alongside its higher tumour recall and false-positive volume. No additional tuning was performed after test evaluation.
- 2026-10-22: Keep portfolio failure analysis explicitly retrospective and exploratory; it uses the known test outcomes for explanation only. Preserve the original results and selection files.
- 2026-10-22: Do not publish the trained checkpoint without a separate rights and distribution review. The public figure is an adapted MSD Task01 visualization with CC BY-SA 4.0 attribution.
